# 교육생 출석관리 시스템 V0 설계서

## 1. 프로젝트 개요

### 1.1 목적

교육 과정의 교육생 출석 현황을 관리하기 위한 웹 기반 출석관리 시스템을 구축한다.

기존 엑셀/구글시트 형태의 출석부를 웹 시스템으로 전환하여 다음 업무를 편리하게 수행할 수 있도록 한다.

* 교육생 기본정보 관리
* 과정/기수 관리
* 일자별 출석시간 관리
* 교육생별 누적 출석시간 확인
* 출석률 및 결석 현황 확인
* 중도탈락/퇴소자 관리
* 프로젝트 자료 제출 여부 관리
* 출석 데이터 검색 및 필터링
* 출석 데이터 엑셀 다운로드

## 2. 주요 사용자

### 관리자

교육 운영 담당자가 사용하는 계정이다.

주요 기능:

* 과정 생성 및 관리
* 교육생 등록/수정/삭제
* 출석 데이터 등록 및 수정
* 일자별 출석 관리
* 교육생 상태 변경
* 출석 현황 조회
* 엑셀 다운로드

## 3. 전체 화면 구성

웹 시스템은 다음 메뉴로 구성한다.

### 좌측 사이드바

* 대시보드
* 과정 관리
* 교육생 관리
* 출석 관리
* 출석 통계
* 퇴소/중도탈락 관리
* 설정

### 상단 영역

* 현재 과정명
* 현재 기수
* 검색
* 관리자 계정
* 알림

# 4. 대시보드

관리자가 로그인하면 가장 먼저 확인할 수 있는 화면이다.

### 상단 통계 카드

다음 정보를 카드 형태로 표시한다.

| 항목     | 설명                  |
| ------ | ------------------- |
| 전체 교육생 | 현재 과정에 등록된 전체 교육생 수 |
| 정상 교육생 | 정상 수료 상태 교육생 수      |
| 퇴소자    | 퇴소/중도탈락 교육생 수       |
| 금일 출석  | 오늘 출석한 교육생 수        |
| 금일 결석  | 오늘 결석한 교육생 수        |
| 평균 출석률 | 전체 교육생 평균 출석률       |

### 하단

#### 오늘의 출석 현황

교육생별로 다음 정보를 표시한다.

* 이름
* 교육생 ID
* 출석 상태
* 입실 시간
* 퇴실 시간
* 교육시간
* 비고

#### 출석률이 낮은 교육생

출석률이 낮은 교육생을 별도로 표시한다.

예:

> 출석률 80% 미만 교육생 5명

# 7. 핵심 기능 - 출석 관리

첨부된 이미지와 동일한 형태의 **날짜별 출석 관리 화면**을 제공한다.

## 7.1 출석부 화면

상단:

> GOOGLE 1기

과정명과 기수를 크게 표시한다.

### 필터

* 과정
* 기수
* 시작일
* 종료일
* 교육생 검색
* 출석상태
* 전체/정상/퇴소

## 7.2 출석 테이블

첨부 이미지와 같이 가로 방향으로 날짜를 표시한다.

예:

| 번호 | 이름  | 교육 ID     | 연락처     | 이메일 | 출석시간 | 4/20 | 4/21 | 4/22 | 4/23 | ... |
| -- | --- | --------- | ------- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| 1  | 강수장 | KOSA59494 | 010-... | ... | 6957 |  240 |  240 |  240 |  237 | ... |
| 2  | 김도균 | KMD78465  | 010-... | ... | 6725 |    0 |  240 |  240 |  240 | ... |
| 3  | 김도연 | KDH018465 | 010-... | ... | 6133 |    0 |  169 |  240 |  240 | ... |

### 출석시간 표시

기본 단위는 **분(minute)**으로 저장한다.

예:

* 240 = 4시간
* 120 = 2시간
* 60 = 1시간
* 0 = 결석

관리자 화면에서는 필요에 따라 다음과 같이 표시할 수 있다.

> 240분 (4시간)

# 8. 출석 상태

각 날짜의 셀은 출석시간과 상태를 함께 관리한다.

### 상태 종류

* 출석
* 지각
* 조퇴
* 결석
* 공가
* 병가
* 외출
* 기타

### 화면 색상

* 출석 → 기본 색상
* 지각 → 주의 색상
* 조퇴 → 주의 색상
* 결석 → 빨간색
* 공가 → 파란색
* 병가 → 보라색
* 퇴소 → 회색

단, 색상은 V0 기본 디자인을 사용하고 전체적으로 깔끔한 관리자용 UI를 유지한다.

# 9. 출석 데이터 입력

날짜 셀을 클릭하면 출석 상세 팝업을 표시한다.

### 출석 상세

교육생:

> 김도균

날짜:

> 2026-05-20

상태:

> 출석

입실시간:

> 09:00

퇴실시간:

> 18:00

교육시간:

> 480분

비고:

> 정상 출석

### 버튼

* 저장
* 취소

# 10. 일괄 출석 입력

관리자가 하루 단위로 출석을 입력할 수 있도록 한다.

예:

> 2026-05-20 출석 관리

전체 교육생을 리스트로 보여준다.

| 교육생 | 상태 | 입실    | 퇴실    | 교육시간 |
| --- | -- | ----- | ----- | ---: |
| 강수장 | 출석 | 08:55 | 18:00 | 480분 |
| 김도균 | 출석 | 09:02 | 18:00 | 478분 |
| 김도연 | 결석 | -     | -     |   0분 |

상단에 다음 버튼을 제공한다.

* 전체 출석
* 전체 결석
* 저장

# 11. 날짜 관리

출석부의 날짜 헤더를 자동으로 생성한다.

과정의 교육기간이

> 2026-05-06 ~ 2026-12-11

이라면 해당 기간의 날짜를 자동 생성한다.

### 주말

토요일/일요일은 기본적으로 교육일에서 제외한다.

### 공휴일

공휴일은 별도로 관리하며 출석시간 계산에서 제외한다.

예:

> 2026-06-06 현충일 → 교육일 제외

# 12. 출석시간 계산

교육생별 총 출석시간을 자동 계산한다.

예:

일일 교육시간:

> 480분

교육생의 출석 데이터:

> 480 + 480 + 240 + 0 + 480

총 출석시간:

> 1,680분

화면에서는:

> 28시간

으로 표시한다.

# 13. 출석률 계산

출석률:

> 실제 출석시간 ÷ 총 교육 예정시간 × 100

예:

총 교육 예정시간:

> 1,200시간

실제 출석시간:

> 1,080시간

출석률:

> 90%

## 13.1 출석률 표시

진행률 형태로 표시한다.

예:

> ██████████████████░░ 90%

또는 숫자로:

> 90.0%

# 14. 공가 관리

교육생의 공가를 별도로 관리한다.

공가 등록 시:

* 교육생
* 날짜
* 공가 사유
* 증빙서류
* 승인 여부
* 관리자 메모

공가 승인 시 해당 날짜의 출석부에는:

> 공가

로 표시한다.

공가일은 출석률 계산에서 제외할 수 있도록 설정한다.

# 15. 퇴소 / 중도탈락 관리

첨부 이미지 하단의 퇴소자 영역을 웹에서도 별도로 관리한다.

### 퇴소자 목록

| 상태 | 이름  | 교육 ID   | 연락처     | 이메일 | 퇴소일        | 사유     |
| -- | --- | ------- | ------- | --- | ---------- | ------ |
| 퇴소 | 김민우 | KMV4594 | 010-... | ... | 2026-05-20 | 개인사유   |
| 퇴소 | 박윤희 | PYO8465 | 010-... | ... | 2026-05-21 | 적성 불일치 |

### 퇴소 처리

교육생 관리 화면에서

> 퇴소 처리

버튼을 누르면 팝업을 표시한다.

입력:

* 퇴소일
* 퇴소 사유
* 상세 사유
* 비고

처리 후 해당 교육생은 정상 교육생 목록에서 분리한다.

# 16. 프로젝트 자료 회신 여부

교육생별 프로젝트 자료 회신 여부를 관리한다.

상태:

* 미회신
* 회신완료

화면:

> 프로젝트 자료 회신 여부: ● 회신완료

미회신자는 관리자 화면에서 쉽게 확인할 수 있도록 한다.

# 17. 자격증 관리

교육생별 자격증 정보를 등록한다.

여러 개의 자격증을 등록할 수 있도록 한다.

> 엑셀 다운로드

# 20. 고정 영역

출석 데이터가 많아지면 가로 스크롤이 필요하므로 다음 컬럼은 화면에 고정한다.

### 왼쪽 고정

* 번호
* 이름
* 교육 ID
* 연락처
* 이메일
* 총 출석시간

날짜 영역만 가로 스크롤한다.

상단 날짜 행도 고정한다.

따라서 스크롤을 내려도

> 이름 + 날짜

를 쉽게 확인할 수 있어야 한다.

# 25. V0 화면 디자인 요구사항

전체적인 디자인은 **교육기관 관리자용 시스템** 느낌으로 제작한다.

### 디자인 방향

* 깔끔한 관리자 Dashboard
* 과도한 장식 제거
* 정보 밀도가 높은 UI
* 테이블 중심
* 날짜별 출석 확인이 가장 중요한 기능
* 엑셀보다 보기 편한 웹 UI
* 반응형 지원
* 데스크톱 화면 최적화

### 색상

메인 컬러는 블루 계열을 사용한다.

출석 상태는 상태별로 명확하게 구분한다.

### 테이블

* 헤더 고정
* 좌측 기본정보 컬럼 고정
* 날짜 컬럼 가로 스크롤
* 행 hover 효과
* 셀 클릭 가능
* 출석 상태별 배경색
* 숫자 중앙 정렬

# 26. V0에 입력할 핵심 프롬프트

다음 요구사항을 기반으로 교육기관용 출석관리 웹 시스템을 만들어줘.

교육 과정별 교육생 출석을 관리하는 관리자용 웹 서비스다.

첨부한 출석부 이미지처럼 교육생을 행으로 표시하고 날짜를 열로 표시하는 출석 테이블이 핵심 화면이다.

상단에는 과정명과 기수, 교육기간을 표시하고 전체 교육생 수, 정상 교육생 수, 퇴소자 수, 평균 출석률을 Dashboard 카드로 표시한다.

출석부의 왼쪽 컬럼은 번호, 이름, 교육 ID, 연락처, 이메일, 총 출석시간을 표시하고 이 영역은 고정한다.

오른쪽에는 교육 날짜를 가로 방향으로 표시한다. 날짜 영역은 가로 스크롤할 수 있도록 한다.

각 날짜의 셀에는 교육생의 출석시간을 분 단위로 표시한다. 예를 들어 240은 240분 출석을 의미한다.

날짜 셀을 클릭하면 출석 상세 수정 모달을 열고 출석상태, 입실시간, 퇴실시간, 교육시간, 비고를 수정할 수 있게 한다.

출석상태는 출석, 지각, 조퇴, 결석, 공가, 병가, 외출, 기타를 지원한다.

교육생별 총 출석시간과 출석률을 자동 계산한다.

관리자는 과정, 기수, 교육생 상태, 출석상태, 이름/교육ID/연락처를 기준으로 검색 및 필터링할 수 있어야 한다.

과정 관리 메뉴에서는 과정명, 기수, 교육기간, 일일 교육시간을 관리한다.

교육생 관리 메뉴에서는 이름, 교육 ID, 연락처, 이메일, 자격증, 프로젝트 자료 회신 여부, 상태를 관리한다.

퇴소 처리 기능을 제공하고 퇴소한 교육생은 별도의 퇴소자 목록에서 관리한다.

공가 관리 기능을 제공하며 공가일은 출석률 계산에서 제외할 수 있도록 한다.

엑셀 다운로드 버튼을 제공한다.

UI는 Next.js + TypeScript + Tailwind CSS + shadcn/ui 스타일의 현대적인 관리자 페이지로 구성한다.

초기에는 실제 DB 없이 Mock Data로 동작하도록 한다.

특히 출석부는 첨부 이미지처럼 데이터가 많아도 보기 편해야 하므로 테이블 헤더 고정, 왼쪽 기본정보 컬럼 고정, 날짜 영역 가로 스크롤 기능을 반드시 구현한다.

데스크톱 화면을 우선으로 디자인하고 실제 교육기관에서 사용하는 출석관리 시스템처럼 깔끔하고 정보 밀도가 높은 UI를 만들어줘.
